# Забияка Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a small standalone OpenCode plugin that observes the last 20 user/model messages, semantically classifies the interaction, maintains aggression from 0–100, probabilistically intervenes, generates rude-but-bounded wording through the current OpenCode model, and publishes the result as a separate Zabiyaka message.

**Architecture:** One local OpenCode plugin split into small TypeScript modules. Deterministic core logic owns context, semantic-result validation, aggression transitions, and adaptive intervention probability; OpenCode integration owns event wiring, model invocation, and separate-message publication. The LLM never decides whether to intervene or how state changes.

**Tech Stack:** TypeScript; OpenCode plugin API/SDK verified against the current OpenCode source and docs; Vitest for deterministic unit/integration tests; npm-compatible package metadata only where required by the OpenCode plugin loader.

**Spec:** `docs/superpowers/specs/2026-09-04-zabiyaka-design.md`

## Global Constraints

- OpenCode only for v1.
- No dependency or integration with Superpowers; Superpowers is only the structural inspiration.
- No MCP, database, persistence, HTTP server, daemon, external long-term memory, or other coding-harness integration.
- No keyword-trigger engine and no separate classifier/model service.
- Own context contains at most 20 relevant user/model conversational messages.
- Aggression is an in-memory integer/number clamped to `0..100`.
- Semantic categories are exactly `conflict`, `continuation`, `provocation`, `ordinary`, and `apology`.
- Intervention baseline is `P = 0.02 + 0.23 * aggression / 100`, yielding 2%, 10%, and 25% at aggression 0, 50, and 100.
- Apology from any aggression level immediately resets aggression to 0 and causes a forgiveness response when Zabiyaka speaks.
- The plugin owns intervention and state; the LLM only supplies wording.
- Current OpenCode session model is the default; configured model override is optional.
- Zabiyaka output is a separate message through a verified OpenCode-supported mechanism.
- Avoid threats, hate speech, and targeted abusive content; rude banter is limited to the plugin interaction.
- Prefer the smallest implementation supported by the current OpenCode API.

export function interventionProbability(aggression: number): number {
